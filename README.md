## ✨ Что это

**VIBE-CODE** — это платформа генерации кода на базе ИИ, где вы пишете один промпт, а два специализированных агента делают всю работу: один планирует и рецензирует, второй пишет production-ready код. Результат автоматически попадает в Pull Request в ваш репозиторий с готовыми release-заметками.

<div align="center">

| 🧠 Планировщик | ⚡ Кодер |
|:---:|:---:|
| Разбивает задачу на шаги | Пишет полный, рабочий код |
| Рецензирует и оценивает | Итерирует до одобрения |

</div>

## 🎯 Возможности

- **Два агента в тандеме** — Planner и Coder работают вместе с автоматическим циклом рецензирования
- **Подключение к интернету** — агенты могут подтягивать реальные данные (поиск, погода, новости, финансы) перед написанием кода
- **Глубокая интеграция с Git** — авто-чтение репозитория, отдельная ветка, коммиты и автоматический Pull Request
- **Вложенные чаты** — родительские/дочерние рабочие пространства с наследованием контекста
- **Release Notes** — человекочитаемые заметки об изменениях генерируются автоматически
- **Локальные LLM** — работает на Ollama, без счетов за облачный AI

## 🚀 Быстрый старт

1. **Откройте [сайт VIBE-CODE](https://b3b3097.github.io/VIBE-CODE/)** — весь интерфейс уже в браузере.
2. Вставьте ваш GitHub-токен (PAT с правами `repo`) в настройках.
3. Напишите промпт — например: *"Добавь аутентификацию JWT в этот репозиторий"*.
4. Укажите целевой репозиторий и нажмите **Generate**.
5. VIBE-CODE создаст ветку, напишет код и откроет Pull Request за вас.

> Хотите запустить локально? Склонируйте репозиторий и используйте GitHub Actions workflow `generate.yml` — все входные параметры настраиваются при запуске.
